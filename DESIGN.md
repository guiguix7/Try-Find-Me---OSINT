# Design

## Design Direction

Create a coherent and professional interface appropriate for a privacy-focused OSINT platform. The design must communicate:

- Trust
- Clarity
- Technical credibility
- Transparency
- Control
- Privacy

## Constraints

- No filler dashboards.
- Every element has a purpose.
- Accessibility AA (WCAG 2.1).
- English copy.
- No decorative charts, meaningless statistics, fake activity indicators, or fictional audit results.
- Risk never conveyed by color alone.
- Responsive for desktop, tablet, and mobile.

## Process

1. Analyze what already exists in the repository.
2. Propose a visual direction based on the project's identity.
3. Deliver navigation architecture, screens, and flows for the five steps.
4. Deliver a small design system (tokens, components, states).
5. Output for approval before any frontend work starts.
