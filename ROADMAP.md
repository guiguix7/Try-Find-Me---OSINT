# Roadmap

See `docs/roadmap/roadmap.md` for the detailed project roadmap.

## Phases

- **Phase 0 — Foundation:** Threat model, privacy documentation, AGPL-3.0 license, project architecture, folder structure, Docker Compose, safe logging, evidence contract, development and contribution documentation, security reporting instructions.
- **Phase 1 — MVP:** Domain verification, DNS TXT proof, passive subdomain discovery, DNS information, RDAP, SSRF protection, evidence contract implementation, DEIP report, tests.
- **Phase 2 — Independent password module and email:** Client-side SHA-1 password module, Pwned Passwords range API, local matching, email ownership confirmation, SMTP configurable by user.
- **Phase 3 — Reports and quality:** JSON export, PDF export, internationalization, accessibility improvements.
- **Later — Profile ownership claims:** Only after implementing a real control-proof mechanism.

## Permanently Excluded

Searching people by name or photo, facial recognition, doxxing, active scanning, brute-force, credential stuffing, password guessing, authentication bypass, unauthorized account access, vulnerability exploitation, active requests to target infrastructure.
